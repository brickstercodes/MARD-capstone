# 40 — Literature log: papers reviewed, sources verified

**Status:** Living document, started 2 Aug 2026 · Owner: Track 1 (Anugrah Shetty) · Updated by: whoever reads a paper for the first time

This log prevents re-checking the same source twice, enforces `CONTEXT.md` §4.3 evidence discipline (every citation is verified against the primary record, not a summary), and surfaces unverified claims early. Every row is a paper or technical source actually read. If a source is mentioned but not in this table, it has not been verified and should not be cited.

**How to use this:**
1. Before writing any number or claim into a draft, check this table.
2. If it's here and marked ✓, the citation is ready to use — quote what's in the "Primary finding" column, cite the source.
3. If it's here and marked `[UNVERIFIED]`, do not use it in the paper yet — follow the Notes to see what's still needed.
4. If it's not here, you need to read it, add a row, and mark the status. See template at the bottom.

## Template for adding a new entry

```markdown
| # | Paper title | Authors | Year | Venue/Source | Primary finding cited | Relevance to MARD | Section/Table verified against | Status | Verified by (name) | Notes |
|---|---|---|---|---|---|---|---|---|---|---|
| n | [Title] | [All authors, in order from the paper] | YYYY | [Full URL or venue name; if arXiv, include the ID] | [Exact quote or paraphrase with **page/table number**; what would go in the paper] | [Why this matters for MARD's claim or methodology] | [e.g., "Figure 3, Table 2, §4.1"] | ✓ Verified / [UNVERIFIED] / ⚠ Partial | [Your name] | [Any caveats: e.g., "this is for depth=1 only," "pricing may change," "from preprint not journal"] |
```

**Rules for this table:**
- **Every row is a paper you have actually read.** If it's mentioned in conversation but not read, do not add it yet.
- **Primary finding** is quoted or closely paraphrased with a source location (page, table, figure). This is what goes into a draft without further checking.
- **Status:** use ✓ Verified only if the primary finding is confirmed by the source. Use `[UNVERIFIED]` if you couldn't confirm it or the source doesn't exist yet. Use ⚠ Partial if you read part of it but not the section you need.
- **Notes** are for you and future readers — context only the table doesn't capture. If the paper is from 2024 and newer versions exist, say so.
- **Verification debt** is for sources cited in project docs (like CONTEXT.md) that haven't been read yet. Don't block work on them, but don't cite them in the paper either until they move to the main table.

## How this feeds into the final paper

When you write §2 Related Work for Manuscript A or B, you use the **Status ✓ Verified** rows only, each with its source URL. Every citation in the final PDF traces back to a row here with the exact section/table/figure that supports it. A reviewer asks "where do you get that number?" — you point them to this log and the source.

If a number doesn't have a row, it hasn't been verified for publication and should not be in the draft.
